# Second gate: inspection before implementation

The first gate is `scripts/run_nlst_gate.py`, with completed artifacts in `results/nlst_gate/`. G0 is the current 864-dimensional global vector (zero-padded to match concatenated width); G1 concatenates current and real future; G2 concatenates current and real delta; G3 concatenates current and the validation-selected objective-A predictor ensemble. Its split, target and feature manifests are saved and will be copied and compared verbatim.

The cache contains 2,984 mean-pooled COLIPRI vectors for 999 patients and 1,984 consecutive pairs. The split is 599/200/200 patients; no new split or cohort is allowed. Targets are the *future scan's* existing `primary_future_cancer_1y/2y/3y` labels, excluding diagnosis on/before that landmark and masking inadequate follow-up. The primary task remains 2y. This is a cancer-enriched, previously inspected development cohort.

Global embeddings and extraction checkpoint provenance remain at `outputs/colipri_decodability/mean/cache/` and `outputs/colipri_decodability/metadata.json`. Preprocessing was official COLIPRI RAS/2mm resampling/HU clamping/192³ crop or pad. No image extraction, COLIPRI training, or new disease-state representation is needed for this second gate.

The existing predictor is `DeltaPredictor` in `scripts/run_colipri_latent_world_model_ablation.py`: LayerNorm, scalar-time 1→32→32 MLP, and (864+32)→1024→1024→864 GELU MLP with dropout 0.1. Objective A is standardized delta MSE. Five checkpoints and cached predictions exist. The original used realized interscan days. The new primary analysis uses a configured 365-day forecast horizon available at inference. The old checkpoint ensemble is reevaluated at that horizon; its original realized-interval output is reproduced separately and clearly marked retrospective legacy, excluded from current-only gate decisions.

The SAME network class is imported for C1–C4. The retained geometric term is standardized future error (algebraically equal to original standardized delta MSE), plus an explicit small standardized-delta SmoothL1 term. Direct-state parameterization and residual/delta parameterization differ only in output interpretation/scaling, not backbone capacity. Raw state and delta errors are algebraically identical, so adding a delta loss is not presented as adding independent information. A geometry-only retrain control isolates changes in checkpoint selection and schedule from clinical loss, and a risk-only control isolates outcome supervision from reconstruction.

Existing `GateModule`, validation-best fit helper, metrics, masked BCE, and training-only scalers are reused. Lightning and offline W&B are configured. New seeds remain 42, 123, 2026. Linear and 128-unit MLP future-only oracle heads are trained first; their ensemble family is chosen by validation 2y AUROC and frozen. Predictor weight grids and direct/residual selection use validation only, before any new test comparison.

No full world model or optional disease-space expansion is part of this gate.
