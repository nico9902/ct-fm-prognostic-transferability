\caption{Design of the native-token masking analysis. (a) Native encoder tokens containing any voxel of the primary tumour (GTV) were hidden. The control hid the same number of tokens around the GTV shape translated within the same axial level. Retained positions were outside both footprints, so all conditions were pooled over identical positions. (b) The CT input was unchanged; hidden tokens were excluded inside the frozen encoder, so that the remaining tokens could not receive information from them, and their own outputs were excluded from the pooling. (c) Each condition was pooled, passed to the PCA16 Cox head and compared with paired bootstrap intervals. The schematic shows a single axial level; masking was applied to the three-dimensional token grid.}
\label{fig:masking}
